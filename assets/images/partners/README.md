## Notas de manutenção

- A grafia oficial é **Panozon**; a lista recebida usava “Panozom”.
- Os logotipos pertencem às respectivas marcas. Exibi-los preservando suas proporções e cores.
- O SVG fornecido pela Syllent contém a imagem PNG incorporada pelo próprio fabricante.
- O PNG da HTH mede 110 × 111 px; preferir exibição de até 80 px de altura.
- Os arquivos devem ser servidos localmente para que a página não dependa de requisições aos sites das marcas.
