# Fontes da galeria de serviços

Os 21 arquivos recebidos foram preservados em `originals/` com nomes descritivos e o sufixo `-original`. As versões publicadas ficam em `assets/images/services/`, todas em JPEG com 1280 × 960 pixels (proporção 4:3).

Dez capturas de tela de modelos hidráulicos foram reconstruídas com a ferramenta integrada de edição de imagens para remover barras de status, botões, margens e controles do aplicativo. A geometria, as tubulações, os equipamentos e as cores do material técnico foram mantidos como referência principal.

Três fotografias verticais de instalações foram expandidas lateralmente para 4:3 com a mesma ferramenta. As outras oito fotografias já estavam em 4:3 e receberam apenas padronização de tamanho, formato e nomenclatura.

## Prompt dos modelos técnicos

> Use case: precise-object-edit. Asset type: 4:3 landscape image for a website carousel about professional swimming-pool hydraulic design. Transform this phone screenshot into a clean presentation image of the technical 3D hydraulic model. Remove the complete phone screenshot interface, including status bar, clock, battery, application title, navigation bar, toolbar icons, margins and any other mobile UI. Reframe the technical model as a polished standalone technical visualization. Preserve the original geometry, pipes, fittings, equipment positions and pipe colors as faithfully as possible. No new labels, decorative text, logos or watermark.

## Prompt das fotografias verticais

> Use case: precise-object-edit. Asset type: 4:3 landscape project photo for a swimming-pool hydraulic services website carousel. Convert this vertical job-site photo into a natural horizontal 4:3 photograph. Expand the scene laterally using the existing equipment room surroundings, improve clarity, exposure and color balance, and keep the complete central hydraulic installation large and centered. Preserve the actual pumps, filters, pipes, valves, fittings, equipment arrangement and installation geometry. No phone interface, app icons, text overlays, added logos or watermark.
